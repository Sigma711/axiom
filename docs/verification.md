## 可重复的检查

make ci 统一执行格式、严格 Clippy、类型检查、构建、测试及覆盖率。make coverage 独立要求前后端、每个产品模块和组件严格超过 95%，仅排除工具、生成产物与测试夹具。

make verify-published 要求干净工作树及已发布提交，检查概念 GitHub 链接与精确源码范围。源码坐标由语法树在构建时定位，链接固定到不可变提交；代码移动后新构建自动更新位置，旧链接仍指向旧版本。

make deploy 执行发布检查并原子切换 AXIOM 专属 release，核验加密、A股、美股实际数据拉取，失败时回滚。部署不修改其他服务。验收同时检查本地 8080，避免静态资源与后端版本不一致。

测试报告及截图由 CI 保存。后续每次发布以该次 CI 产物和运行验证为准；自动化断言不能保证未来第三方数据永不缺失或被修订。
