## 发布核对

`make verify-published` 要求工作区干净，主动获取 `origin/main`，确认当前提交已发布，然后核验所有概念的 GitHub 提交号与精确行范围。源码坐标由 AST 重新生成，不写死行号；旧链接固定到不可变提交。

8080 服务应在提交后经 `make serve` 重新构建启动，再核对实时目录、GitHub 链接与浏览器实际操作。该步骤避免只更新静态资源、继续运行旧后端而造成实践目录 404。

自动化检查覆盖已明确的契约与回归情景，不能代替外部行情质量、闭源指标原始算法或所有未来市场情景的验证。书中专有指标按已公开资料解释，并明确显示导入信号或教学输入的边界。
