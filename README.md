# AXIOM

AXIOM 是一套量化交易开发学习平台，可以[在线体验](https://sigma711.top/axiom/)，也可以在本地运行。它把“拿到行情”到“模拟成交”的过程拆开，让第一次写策略的人看清每个数字从哪里来、怎样计算、何时能够用于决策。页面上的回测和模拟盘不会发送真实订单。

## 学什么

从学习中心的概念速览和原书阅读起步，再到指标大全、因子研究、创建策略、数据探索、回测、策略对比和模拟盘动手。指标大全解释公式、图形和适用边界；因子研究逐项介绍 WorldQuant Alpha101 与 Qlib Alpha158，并用可核验的真实日线检验已经具备数据和实现条件的因子。回测和策略对比让同一套规则在历史行情中接受检验，模拟盘用虚拟账户检查信号、成交、持仓和净值的先后顺序。

## 一条策略怎样走完

`市场数据 → 标的池 → 因子 → 策略信号 → 仓位与风控 → 模拟成交 → 业绩复盘`

市场数据要先核对时间、复权和缺失值。因子只是把行情或基本面压缩成一个可比较的数；策略才决定何时买卖。当前 K 线产生的信号不能在同一根 K 线的过去成交。回测还要计入手续费、滑点和仓位限制，并在不同样本上复查结果。漂亮的净值曲线不能代替这些检查。

React 负责展示和交互；Rust 服务读取行情、计算指标和因子、运行回测并推进模拟账户。页面保留数据来源和计算口径，让人能沿着行情、公式、信号、成交查回每一步。缺少必要原始数据的因子会明确标出，不会编造数值。

## 运行、测试与部署

本地需要 Rust 工具链、Node.js、npm 和 make。在仓库根目录运行：

```sh
make setup   # 首次安装依赖
make serve   # 启动服务，访问 http://localhost:8080
make test    # 运行测试
make ci      # 运行完整发布检查
```

发布到 [sigma711.top/axiom](https://sigma711.top/axiom/) 前，在 `main` 提交并推送，确认本地与 `origin/main` 一致，然后运行 `make deploy`。部署需要已配置的 `root@sigma711.top` SSH 访问；命令会运行 CI、检查源码链接、构建并发布前后端，验证线上真实数据接口，失败时恢复上一版。发布只改动 `/axiom` 对应服务。
